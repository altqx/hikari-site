**File › Settings** opens the Settings window. It holds every setting in one place: a search field at the top, the pages and their sections in a contents list on the left, and the rows of every page in one list you can scroll through. It reopens where you were. The [Settings reference](/en/docs/reference/settings) lists every setting with its default; this page is about the window itself.

## Pages

| Page | Holds |
| --- | --- |
| **General** | The interface language, tabs, saving and autosave, notices, folders, the [trusted folders](/en/docs/automation/running-scripts#scripts-a-subtitle-file-names) and, at the end, **Legacy**: importing HikariSub 0.0.x settings and shortcuts |
| **Appearance** | The [theme](/en/docs/customize/themes), accent, program font, preview text and title bar |
| **Line editor** | How the text shows, editing, Translation mode and the tag buttons |
| **Editing** | The values the [Cycle commands](/en/docs/basics/grid#cycling-tags) step through |
| **Spelling and grammar** | [Spelling](/en/docs/checking/spelling) and the [grammar check](/en/docs/checking/grammar) with its rule groups |
| **Grid** | The active line, columns, counting with the reading limits, splitting and new lines |
| **Video** | Playback, subtitles on the video, decoding and the script resolution |
| **Audio** | The output device, playback, snapping, karaoke and the cache |
| **Conversion** | How another format is converted when you [save it as ASS](/en/docs/basics/files-and-formats#saving-as-ass), and the export format |
| **Script properties** | The credits written into Script Info on save, and saving the panel layout in subtitle files |

| **Plugins** | Each plugin's own settings, one section per plugin: see [Plugin settings](#plugin-settings) |

Some rows show only where they apply: the video player and the audio API only on Windows, for example.

Some panels open their page directly: **Audio settings** in the Audio panel's speaker menu, **Spelling settings…** in the Spellchecker when it finds no dictionary, **Grammar settings…** in its Grammar mode while grammar check is off, and **Shortcuts in Settings…** in the Automation panel's menu.

## Searching

Type in **Search settings** to find a setting by its label, its note or its id, such as `grid.autoHideColumns`. The rows and the contents list show only what matches. <kbd>Ctrl</kbd>+<kbd>F</kbd> goes to the field from anywhere in the window, and <kbd>Esc</kbd> clears it.

- **Filter**, beside the field, adds a filter to the search: **Modified** keeps only the settings that are changed, and **Plugin ›** one plugin's settings. A filter shows in the field as `@modified` or `@plugin:` and the plugin's id. You can type one too, and <kbd>Backspace</kbd> removes it whole.
- When commands match as well, the results end with **Shortcuts**: up to five commands with their keys, and **Show all N shortcuts**, which opens the Shortcuts page with the search filled in.
- With no match, the window says so, such as "No settings match “kara”."

## Yours and Project

In a window with a [Project](/en/docs/basics/files-and-formats#projects) open, two tabs sit above the rows:

- **Yours** holds your own settings. A row this Project sets says *Set in this project*, with a link to it.
- **Project**, named after the folder, such as **Project: my-show**, holds the settings this Project sets for everyone who opens it, kept in its `.hikari/project.toml`. It shows only the settings a Project can set. A row the Project doesn't set says *Uses yours*. Its reset button, **Use yours**, takes the Project's value away.

A row set in `.hikari/project.local.toml` says *Set in project.local.toml* and can't be changed here. A Project setting that widens what HikariSub may do says *Waits for trust* until you [trust the folder](/en/docs/basics/files-and-formats#project-scripts).

## Rows

Each row has its label, a note under it, and its control. A setting that differs from its default shows *Changed* after its label, and a reset button that puts it back. Each row's **⋯** menu has **Reset**, **Copy setting id**, **Copy link** and **Open settings file**.

## Plugin settings

Each plugin with settings has its own section under **Plugins**, at the end of the contents list, with its name, version and description, and **Manage plugin…**, which opens it in the plugin manager. A plugin that is turned off keeps its section, which says its settings apply when it's on. With no plugin that has settings, it says "No plugin has settings."

## Preview text

**Appearance › Font › Preview text** is the text of every style and font sample: the Style manager's preview, the samples in the [Styles panel](/en/docs/basics/styles#the-styles-panel), and the samples and preview in [Manage font catalogues](/en/docs/typesetting/fonts#font-catalogues). The font picker shows it when there is no selected text or line text to draw. Its note reads "The sample text of the style and font previews."

- The default is `光 Hikari 日本`.
- A change applies at once, to every sample that is open.
- Leave it empty to use the default.
- Editing the text under the Style manager's preview changes this setting too.
- A stored `Podgląd`, the old default, reads as `光 Hikari 日本`, also when **Import settings** brings it over. Any other text you chose is kept.

## When changes apply

Every change applies at once and is saved at once: the window has no OK, Cancel or Apply, and closing it loses nothing. Only the settings you changed are written.

- Check boxes, choices, sliders and pickers apply as you change them.
- A text or number field applies when you press <kbd>Enter</kbd>, when you leave it, or half a second after you stop typing. <kbd>Esc</kbd> in the field puts back the value it had.

Changes take effect without restarting, the interface language too. Where a setting waits for something, its note says so, such as "Applies when the video opens again."

## Resetting

- **Reset page…**, in the right-click menu of a page in the contents list, puts that page back to its defaults after asking.
- **Reset all…**, at the bottom of the window, puts every page back after asking. It leaves your shortcuts and the appearance alone: reset them on their own pages.

Both apply at once, like any other change.

## Keyboard

The window opens with the cursor in the search field. <kbd>Tab</kbd> moves through the window, and <kbd>Ctrl</kbd>+<kbd>F</kbd> goes back to the search. <kbd>Esc</kbd> clears the search first, then closes the window. <kbd>F1</kbd>, or the **?** in the title bar, opens this page.

## Setting links

**Copy link** in a row's **⋯** menu copies a link to that setting, such as `hikarisub://settings/grid.autoHideColumns`. Opening the link opens the Settings window at that setting and highlights it. A link never changes a value.

- `?scope=project` at the end opens the Project tab. In a window without a Project, or for a setting a Project can't set, it opens the Yours tab and says why.
- A plugin's setting is `plugin.`, the plugin's id, a dot and the setting's id.
- `hikarisub://settings` alone opens the window where it was.

Plugins can open the window at a setting the same way.

## Where settings are kept

HikariSub keeps one set of settings for each user on the computer, in `settings.toml`, with your shortcuts in `hotkeys.toml`. It has no profiles to switch between.

The files are in your [user folder](/en/docs/automation/user-folder), with your scripts, dictionaries and saved layouts. **Help › Open user folder** opens it.

| Copy | Folder |
| --- | --- |
| Windows setup | `%APPDATA%\HikariSub\` |
| Linux packages | `~/.config/hikarisub/` |
| Portable zip or tar.gz | `user`, in the folder you unpacked |

Uninstalling or updating HikariSub never deletes your settings.

**Open settings file**, at the top of the window or in a row's **⋯** menu, opens `settings.toml` in your system's editor; on the Shortcuts page it opens `hotkeys.toml`. HikariSub watches `settings.toml` while it runs, so an edit you save there shows up in the window within a moment. If the file has a mistake, the window says so, such as "settings.toml has an error on line 12.", and keeps the last values it could read; changes you make in the window wait until it can read the file again. [Settings files](/en/docs/automation/user-folder#settings-files) explains the files.

## Settings from older versions

The **Legacy** section at the end of the General page brings in settings from HikariSub 0.0.x, and shortcuts from Aegisub:

- **Import settings…** opens the import window, which also reads Aegisub's keyboard shortcuts. See [Moving from legacy](/en/docs/get-started/moving-from-legacy#importing-your-settings).
- **Roll back the last import…** goes back to the settings you had before it. It shows only after an import.
- **Import legacy shortcuts…** adds the macro shortcuts of a legacy `Hotkeys.txt` at once.

When no legacy installation is found beside the program, a note under the buttons says so. Your old settings files are never changed. See [Moving from legacy](/en/docs/get-started/moving-from-legacy).
