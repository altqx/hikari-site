The newest release comes first. Each release's notes on GitHub also list its downloads. [Install](/en/docs/get-started/install) has the current version.

## Next release

Not published yet. These changes are in HikariSub's code and come with the next beta.

### New and improved

- **The automation folder is reset once:** HikariSub 0.1.0-beta.4 resets your automation folder once. The karaoke templater and several scripts are now built in, and old copies could replace or break them. Your old `automation` and `config` folders move to `automation-backup-<date>` in your user folder; nothing is deleted. A popup lists what moved, opens the backup, and can reinstall the scripts DependencyControl had installed, at their current versions. Scripts HikariSub now does natively are listed with the command to use instead. Scripts you copied in by hand stay in the backup. If your automation folder only has the scripts HikariSub put there, they're refreshed quietly, with no backup and no popup. See [The automation folder reset](/en/docs/automation/user-folder#the-automation-folder-reset).
- **Faster karaskel and aegisub.util:** karaoke scripts that use `karaskel`, and scripts that use `aegisub.util`'s colour and text helpers, now run faster in HikariSub. They get the same results as before. See [Modules](/en/docs/automation/writing-scripts#modules).
- **A Project's own AI keys:** in a trusted Project's window, **File › Settings › Project › AI** names an environment variable or a `.hikari/credentials.toml` entry for each of your providers. **Create credentials file** makes the file and a `.hikari/.gitignore` that keeps it out of git. A key found in `project.toml` is ignored, with an offer to move it. Base URLs, budgets and on/off stay yours. Environment variables come from HikariSub's own environment, so a desktop launch doesn't see a variable set only in a shell profile. See [Project AI keys](/en/docs/basics/files-and-formats#project-ai-keys).
- **ACP agents:** on Linux, **File › Settings › AI › External agents** now runs ACP agents. HikariSub finds OpenCode (`opencode acp`) and Antigravity (`agy acp`, 1.5.0 or later) on your `PATH`, and **Add agent** adds any other ACP agent. Each agent can write only to its own folders. For Antigravity, press **Sign in with Google…** and paste the code Google's page shows; HikariSub keeps that sign-in in your keychain and never reads `~/.gemini`. The agents appear in the Agent panel's model menu, and their edits go to the review. An agent found only through a mise or asdf shim that can't be resolved now says why on its row. See [ACP agents](/en/docs/ai/agent#acp-agents).
- **Project instructions for the agent:** Hikari AI reads your `AGENTS.md` from the user folder and then the Project's `AGENTS.md`, joined in that order and up to 32 KiB each, in Claude Code, Codex and ACP agent threads too. A bar says when a Project's `AGENTS.md` is on, *This project's AGENTS.md instructions are on*, with **Open** to edit it. The Agent panel's thread list puts the current Project's threads first, under *This project*. See [AGENTS.md instructions](/en/docs/ai/agent#agentsmd-instructions).
- **The agent builds node effects:** AI agents can now build and run node effects. They read a file's graphs, build or change a graph step by step, preview the lines it would write, then save or apply it as one undo step. Saving and applying ask in Manual mode, go to the judge in Auto and run in Full access; agents connected through MCP can't do either. A graph with a Lua node runs only from node effects, never through the agent. See [Building node effects](/en/docs/ai/agent#building-node-effects).
- **Position and alignment commands:** the Grid's menu has **Change alignment, keep position ›**, which sets `\an` and leaves the line where it shows, **Align and distribute ›**, relative to the active line or the video frame, **Position to margins** and **Margins to position**. The Line editor's text menu has **Phantom ›**. **Cycle \blur**, **\bord**, **\shad**, **\alpha**, **\an** and **\fsp**, and their **back** commands, step a tag through a list on the new **File › Settings › Editing** page. The Position shifter has **X** and **Y** fields, and **Copy columns** and **Paste columns** have a **Tags** group. None of them has a key at first. See [Position and alignment](/en/docs/basics/grid#position-and-alignment).
- **A Project's skills, and Skills in Settings:** a Project can bring its own [skills](/en/docs/ai/skills) for the agent in `.hikari/skills`. The Project's come first, then yours, then the built-in ones, and a skill hides any of the same name below it. A thread keeps the skills of the Project it was started in. **File › Settings › AI › Skills** lists the skills a window's threads get, with a **Project**, **Mine** or **Built in** chip, and says why a skill is hidden or can't be offered. **Open folder** and **Open project folder** open the folders. See [Skills](/en/docs/ai/skills).
- **Text to drawing and Combine drawings:** node effects gain **Text to drawing**, which turns a syllable or line into a vector drawing in its style's font, and **Combine drawings**, which unites, subtracts, intersects or excludes two drawings. Each comes with an example under **From a preset**, *Text outlines* and *Striped letters*. Neither exports as template lines. The Drawing tool's **Pathfinder** tooltip now says picked lines combine in Grid order. See [Text and drawings](/en/docs/karaoke/node-effects#text-and-drawings).
- **Project scripts and plugin settings:** a trusted Project can bring its own Automation scripts, autoload scripts in `.hikari/automation/autoload/` and shared modules in `.hikari/automation/include/`. A Project script replaces your script of the same name only in that Project's window, and a module HikariSub ships, such as `ln.kara`, always loads from HikariSub's own copy. In `.hikari/project.toml`, `[plugins]` `enabled` and `disabled` turn your installed plugins on or off for the Project, and `[plugins."<id>"]` changes their settings. In an untrusted Project, the Automation panel and the plugin manager show a lock with **Trust this folder to use them**. When a Project uses a plugin you don't have, the plugin manager offers **Install from the marketplace**. See [Project scripts](/en/docs/basics/files-and-formats#project-scripts).
- **Hikari AI times karaoke:** the agent splits lines into syllables, snaps syllables to where singing starts, times them and runs the Kanji timer, then previews a karaoke template and applies it as one change that waits in the review. If you've installed WhisperX or the Montreal Forced Aligner, it can run it on the song, and asks every time. Nothing is bundled, and the audio is never sent anywhere. See [Timing karaoke](/en/docs/ai/agent#timing-karaoke).
- **Pathfinder and Offset for drawings:** Vector drawing has **Pathfinder**: **Unite**, **Subtract**, **Intersect** and **Exclude** combine the drawing with the line's clip, or with the other picked lines in Grid order, and the entry under the pointer previews on the video. **Offset** grows or shrinks the drawing, with **Miter**, **Round** or **Square** corners, and **Apply offset** writes it. Each is one step in the history. The `Yutils` that comes with HikariSub runs its shape functions natively, with the same results. See [Combining and offsetting drawings](/en/docs/typesetting/visual-tools#combining-and-offsetting-drawings).
- **Translate with a reviewer:** Translate now runs a translator and a reviewer over your Lines and keeps names and terms from Honya's `GLOSSARY.md` and `CHARACTERS.md`. In Translation mode it fills the Translated text and marks Lines the reviewer didn't approve Unconfirmed. A Project can name its translator and reviewer models, but never a key. See [Translating](/en/docs/ai/inline-actions#translating).
- **Long conversations:** the Agent panel compacts long conversations. At 90% of the model's context window it clears old tool results, then summarises older turns. A divider, such as *Context compacted 313K → 21.2K tokens*, opens to show the summary. `/compact`, with an optional instruction, or **Compact conversation** in the thread menu compacts by hand, and **New thread from summary** starts a fresh thread from a summary. The token meter turns amber at 90%. **File › Settings › AI › Agent › Compact long conversations automatically** is on at first; with it off, the panel offers to compact at 97%. The full history stays visible in the panel. See [Long conversations](/en/docs/ai/agent#long-conversations).
- **Project tiers for style catalogues:** a Project can keep its own style catalogues in `.hikari/catalogs/<name>.sty`. The Style manager's **Catalogue** box lists *This project* first, then *Mine*, with a **Project** or **Mine** chip on each. A Project catalogue hides yours of the same name: yours stays listed, muted, and opens read-only. **Catalogue tiers** (**⋯**) copies or moves a catalogue to the other tier, with **Replace**, **Rename** or **Skip** when the name is taken. While a Project is open, **New catalogue** saves to the Project at first, and **Save to mine** is on its arrow; HikariSub remembers the choice. `Last Style Storage` and the Conversion catalogue find the Project's copy first. Shortcuts, AI providers and threads, recent files, window state and Hunspell dictionaries stay yours only. See [Project tiers](/en/docs/basics/project-tiers).
- **MCP servers for the agent:** **File › Settings › AI** has an **MCP servers** list, in the **MCP** section. Add a command on this computer or a streamable-HTTP URL, and the agent in the Agent panel can use the server's tools. The environment and bearer token go to your keychain. A tool that only reads runs without asking, one that may destroy something asks in every mode, and the others ask as any change does, unless you tick **Run … without asking** for that tool. The server's hints about its tools count only when you tick **Trust what this server says about its tools**. See [MCP servers](/en/docs/ai/agent#mcp-servers).
- **Plugins and Projects:** a plugin can read and write the folder of the Project you work in, once you trust that folder, through the new `project` place. `hikari.project.info()` gives the Project's name and whether it is trusted, and the `project.changed` event comes when it changes. The Hikari API adds folders to `files.*`, `project.info` and `project.changed`. See [Folders and files](/en/docs/plugins/using-plugins#folders-and-files).
- **Text on path:** a new visual tool, the 14th on the rail, lays a line's text out along a path, one line for each letter. Take the path from the line's vector clip, or draw it on the video. Choose Left, Centre, Right or Spread, an offset, Reverse and Rotate, or slide the text along the path with **Slide**. **Apply** writes the new lines as one step, and keeps the original as a comment. See [Text on path](/en/docs/typesetting/visual-tools#text-on-path).
- **More splits, and overlapping lines:** the Grid's **Split ›** menu has **At tag blocks**, one line for each tag block with the tags in effect for it, and **Every N frames or seconds…**, which keeps `\move`, `\t` and `\fad` playing as they did. Splits into characters, words, wraps or tag blocks now give a turned line's pieces the line's `\org`, so a rotated sign doesn't jump. **Edit › Select lines** has **Overlapping lines**, for the dialogue lines that start while an earlier one is still on. See [Joining and splitting](/en/docs/basics/grid#joining-and-splitting).
- **Project fonts in the font picker and Font collector:** in a Project's window, the font picker and the Style manager's font list include the Project's fonts. The Font collector finds and copies fonts from the Project's font folders and your Fonts folder, in the order the video uses: attached fonts, the Project's, your Fonts folder, then installed fonts. See [The Font collector](/en/docs/typesetting/fonts#the-font-collector).
- **The video and audio backend loads when it's needed:** HikariSub starts without it, and loads it the first time you open video or audio, or show a list of output devices, so that first action can take about a second longer. Until then, the speaker button's tooltip shows your saved device, or *System default*. See [Output device](/en/docs/basics/audio#output-device).
- **The agent typesets signs:** ask the agent in the Agent panel to typeset a sign, and it reads the sign's corners from the frame while HikariSub's own Perspective, clip, drawing, Position shifter and Hydra tools write the tags. Every line is drawn and checked against the sign before it reaches your review, and if one misses, nothing is applied. See [Typesetting signs](/en/docs/ai/agent#typesetting-signs).
- **Your credits in Settings:** **File › Settings › Script properties** has a **Credits** section for the credits HikariSub writes into each ASS file you save, with **Ask before changing them on save**. Before, they were only in `settings.toml`. In a Project's window, a credit the Project sets says *Overridden in this project*. See [Filling in the credits on save](/en/docs/basics/files-and-formats#filling-in-the-credits-on-save).
- **karaOK presets:** the Template editor's **From a preset** has ten more presets, written in karaOK's template language: Word pop, Word wipe, Letter cascade, Letter shimmer, Furigana rise, Early lead-in, Wave bounce, Shape burst, Line gradient and Thai fade, which keeps Thai vowels and tone marks on their letters. Three of them use ln.kara. A new file starts in karaOK mode, and the Template editor writes karaOK's template words there. A stock preset added to a karaOK file is put in karaOK's words for you. In a file that already uses Aegisub 3.2.2 templates, the karaOK presets are turned off and say how to switch. Thai support is by Jibrill. See [Presets](/en/docs/karaoke/presets#karaok-presets).
- **ln.kara:** HikariSub now comes with `ln.kara`, karaOK's template library, by logarithm with petzku. Load it from a `code once` line with `ln = _G.require "ln.kara"; ln.init(tenv)`. It gives templates tag builders such as `ln.tag.pos`, `ln.tag.move` and `ln.tag.t`, colours (`rgb`, `hsl`), waves, drawings and maths. HikariSub's copy fixes eight of upstream's bugs: among them, `gc`, `ga` and `ln.line.tags` read the line's own tags, `sd()` gives the whole length, and several calls that stopped with an error now work. The Template editor offers `ln.` and its functions as you type. Thai support is by Jibrill. See [The ln.kara library](/en/docs/karaoke/templater#the-lnkara-library).
- **Template language and karaOK export:** the Template editor shows whether a file's templates follow karaOK or Aegisub 3.2.2, and **Template language** switches it. Node effects' **Export as template lines** has two formats: **karaOK templates**, which also sets the file to karaOK, and **Aegisub 3.2.2 templates**, for Aegisub's own templater. HikariSub remembers the last one. In a karaOK file, node effects place text to 0.1 px and keep syllables with no length, as karaOK does. A file on Aegisub 3.2.2's rules can now use karaOK's `style` modifier, its word, character and furigana-character templates, `k_retime` and Lua's `table`, `pairs`, `ipairs`, `tonumber`, `tostring` and `type`, and `furigana_styles = false` in a `code once` line keeps the *-furigana* styles out of the file. Thai support is by Jibrill. See [karaOK templates](/en/docs/karaoke/templater#karaok-templates).
- **Track colour and Find fade:** **Video › Track colour…** follows a point's colour or alpha on the video across the selected lines' frames and writes it as `\t` tags. **Skip repeated colours**, on at first, leaves out frames whose value doesn't change. **Video › Find fade…** writes a `\fad` from where the sign fades in and out. Both read frames without subtitles, can follow After Effects tracking data from the clipboard, and are one undo step. See [Tracking a colour](/en/docs/typesetting/motion-tracking#tracking-a-colour).
- **Blur and glow layers:** **Subtitles › Blur and glow layers…**, also in the Grid and Line editor menus, builds glow, separate-border and stacked 3D-shadow layers under the selected lines. It does natively what ua.BlurAndGlow, lyger's BorderSplit and NecrosCopy's 3D shadow do. The preview shows on the video, and building is one undo step. **Build layers with the last values** builds again from a key. See [Blur and glow layers](/en/docs/typesetting/visual-tools#blur-and-glow-layers).
- **Remove tags:** **Remove tags…**, in the Grid and Line editor menus, removes the tag families you choose from the start block, the inline blocks or all blocks, in the selected lines or the whole file. Clean up can also remove comments, merge adjacent blocks, drop overridden tags, apply the Clean Tags rules, byte for byte as the Clean Tags script does, and delete lines left empty. A preview shows the result, and applying it is one undo step. See [Removing tags](/en/docs/basics/grid#removing-tags).
- **Import lyrics:** **File › Import lyrics…** turns LRC, TTML and decoded Kugou KRC and QQ Music QRC files into lines, word-timed with `\k`. Add them after the last line of the open file, as one undo step, or to a new file. HikariSub detects the encoding, such as GB18030, Big5 or UTF-16, and you can pick another. End times run to the next line or leave a gap, and you set the last line's length. HikariSub doesn't decrypt KRC or QRC files: an encrypted one shows a message. See [Importing lyrics](/en/docs/basics/files-and-formats#importing-lyrics).
- **Lua scripts from the agent:** the agent in the Agent panel can write a Lua Automation script and run it as a macro. Every run asks first, in every mode, Full access included: the card shows the script, with **Run** and **Don't run**, and warns when it needs a DependencyControl module that isn't installed. An approved script runs like any macro, as one undo step, and **Force stop** ends it. It is saved in `ai/scripts` in your user folder and never added to `autoload`. See [Lua scripts](/en/docs/ai/agent#lua-scripts).
- **Line breaks, case and dialogue alternatives:** the Grid's right-click menu and the Line editor's text menu have **Line breaks ›**, to put a balanced `\N` in, move it a word, take breaks out or wrap only at `\N`; **Change case ›**, with lowercase, UPPERCASE, Title Case, Sentence case, Full-width and Half-width; and **Swap dialogue alternatives**, for lines written with `{*}`. They work on the selected lines, leave tags alone and are one undo step. See [Line breaks, case and dialogue alternatives](/en/docs/basics/grid#line-breaks-case-and-dialogue-alternatives).
- **Timing helpers and the timing assistant:** **Subtitles › Timing helpers** snaps a line's start or end to the keyframe before or after it, adds or removes the lead-in and lead-out from **File › Settings › Audio**, moves a start or end by one frame, and extends the line before or after to meet the active one. The Timing postprocessor panel's new **Assistant** tab goes through the lines one by one and suggests a start and end from the panel's rules, saying why: <kbd>Enter</kbd> accepts, <kbd>Alt</kbd>+<kbd>C</kbd> changes the times and <kbd>Alt</kbd>+<kbd>S</kbd> skips. See [Timing helpers](/en/docs/basics/timing#timing-helpers) and [The assistant](/en/docs/basics/timing#the-assistant).
- **Plugins can add node-effects nodes:** a plugin lists its nodes in its manifest's `contributes.nodes`, and they show in **Add node** under the plugin's name. They run in the same sandbox as Lua nodes, need no trust beyond installing and turning on the plugin, and always run the plugin's own code. If the plugin is missing or turned off, the node stays in the graph with a problem naming the plugin and writes nothing. The [Zigzag](https://github.com/altqx/hikari/tree/main/docs/examples/zigzag) example adds one. See [Nodes from plugins](/en/docs/karaoke/node-effects#nodes-from-plugins).
- **AI inline actions:** **AI** in the Grid's right-click menu and the Line editor's runs one AI task on the lines you choose, with one request per line and no Agent panel thread: **Rewrite…**, **Shorten to 15 CPS**, **Fix spelling and grammar**, **Translate to** and your own actions from **File › Settings › AI › Inline actions**. Only the text changes, and override tags stay where they are. In Auto and Full access the results go into the review as one turn and one undo step; in Manual they wait in a list over the Grid for **Apply** or **Discard**. See [Inline actions](/en/docs/ai/inline-actions).
- **Project fonts:** a Project can bring its own fonts. List font folders in `.hikari/project.toml`, such as `fonts = ["fonts", "../common/fonts"]`, and every subtitle file in the Project's window draws with them: on the video, in the style preview and font samples. They come after the fonts attached to the file and before your Fonts folder and installed fonts, so the Project looks the same for everyone who opens it. The Font collector's **Save to** starts at the Project's first font folder. See [Project fonts](/en/docs/basics/files-and-formats#project-fonts).
- **Notices in their own window:** with more than one window open, a notice or question about a tab shows in that tab's window, and notices about HikariSub as a whole, such as updates and crash reports, show once, in the window you used last. Before, every window showed every notice. A crash report now also says how many windows were open, how many tabs each had and which was active, and nothing more about them. See [What each window has](/en/docs/customize/layouts#what-each-window-has) and [Crash and freeze reports](/en/docs/help/what-is-sent#crash-and-freeze-reports).
- **Interpolate across lines:** the Grid's right-click menu has **Interpolate across lines…**, for three or more lines. It fills the lines between the first and the last with the tag values between theirs: positions, colours, alphas, sizes, rotations, clips (drawings point by point) and `\t` tags. It finds the tags that differ by itself, and you can untick any of them. It has acceleration, a shortest-way rotation and a cascade option for `\t` tags. The video shows the result while the window is open, and the change is one undo step. See [Interpolating across lines](/en/docs/basics/grid#interpolating-across-lines).
- **karaOK templates:** the built-in karaoke templater now also runs templates written for karaOK, with its `lsyl`, `lword`, `lchar`, `word` and `furichar` templates, `k_retime` and the `$ci`, `$slen`, `$llen` and `$len` variables. A file uses karaOK when its `[Script Info]` says `Karaoke Templater: karaOK`, or when its templates use something only karaOK has. Other files run as before. The lines are karaOK's, byte for byte, apart from fixes to karaOK's own bugs: words and characters line up on text outside ASCII, `template syl char` runs once per character, `style X` is plain text, and each furigana character takes its own syllable's tags. `char` and `lchar` keep Thai vowel and tone marks on their letters. Thai support is by Jibrill. See [karaOK templates](/en/docs/karaoke/templater#karaok-templates).
- **Project settings in Settings:** while a folder is open as a Project, **File › Settings** has two tabs. **Yours** holds your own settings. **Project** holds the values saved in the folder's `.hikari/project.toml` for spelling and grammar, Script properties and Translation. Each row says whether it uses yours, is set in the project or comes from `project.local.toml`, and **Use yours** clears the project's value. On the Yours tab, a setting the project overrides says so. A Project folder with its own scripts or plugin settings shows a bar asking you to trust it: **Trust folder** or **Not now**. See [The Project tab](/en/docs/basics/files-and-formats#the-project-tab).
- **Highlights and Inline-fx in node effects:** the new Highlights node gives each syllable once per highlight, like the templater's `multi`, and the Inline-fx node keeps the units marked `{\-name}`, like `fx`. From a preset adds two examples, Highlight flashes and Paint and cloud. Export as template lines now writes `multi`, `fx`, and an `fxgroup` for units without an inline-fx. A use a template can't express still blocks the export, with the reason. See [Highlights and inline-fx](/en/docs/karaoke/node-effects#highlights-and-inline-fx).
- **Audio peaks in node effects:** the new Audio peaks node, under Audio in Add node, gives the audio's level over each syllable, or over any span, so effects can follow the music. With no audio open it gives 0, and the graph shows a problem. From a preset adds the example Audio pulse, where syllables grow with how loud the audio is. Audio peaks can't be exported as template lines, because the templater can't read the audio. See [Audio peaks](/en/docs/karaoke/node-effects#audio-peaks).
- **Codex in the Agent panel, and no provider needed:** with Claude Code or Codex installed, the Agent panel is ready without a provider, and a new thread uses that agent. When Codex is installed, the model menu also offers **Codex**: the thread runs on your own `codex` with HikariSub's own ChatGPT sign-in, from **File › Settings › AI › External agents**. It uses only HikariSub's tools, and its edits go to the review. Codex is on Linux only for now. In Manual mode, a Claude Code or Codex edit waits as a proposal for up to a day. See [Agents on this computer](/en/docs/ai/agent#agents-on-this-computer).
- **Export node effects as template lines:** the node-effects graph menu has **Export as template lines**, which adds template lines after the graph line that make the same lines in Aegisub's karaoke templater. All ten karaoke presets export. A graph that uses something a template can't express, such as random numbers, Lua nodes or the Clip gradient, Array and Particles nodes, isn't exported: a popup lists each node that blocks it and why, and choosing one selects it. See [Exporting as template lines](/en/docs/karaoke/node-effects#exporting-as-template-lines).
- **Macros on big files:** macros now run on subtitle files of up to about 64 MB, where before they stopped at about 8 MB. On a larger file the macro doesn't run, nothing changes, and a message box says how much it needs. A macro's edits also go in much faster on big files: one edit on a 20,000-line file takes under 100 ms instead of about 2 s. See [Running a macro](/en/docs/automation/running-scripts#running-a-macro).
- **Open a folder from Windows Explorer or the Linux launcher:** the Windows setup's **Associate subtitle files (.ass, .ssa, .srt, .sub) and folders** adds **Open with HikariSub** to a folder's right-click menu, which opens the folder as a Project. On Windows 11 it is under **Show more options**. On Linux, HikariSub's launcher menu has **Open Folder…**, and the new `--open-folder` switch shows the Open folder picker. See [Opening a folder](/en/docs/basics/files-and-formats#opening-a-folder).
- **The karaoke templater is built in:** HikariSub now runs Karaoke Templater natively, rather than as a Lua script, and the lines it makes are the same as before. The Automation panel marks it **Built-in**: you can reload it, but not edit or unload it. Its two macros keep their names, and the keys you gave them still work. Named line templates now always run in the same order: the unnamed ones first, then the named ones in the order their names first appear. Thai support is by Jibrill. See [Named line templates](/en/docs/karaoke/templater#named-line-templates).
- **Video and audio in each window:** each HikariSub window now plays its own tab's video and audio, and keeps its frame while you work in another. Playing in one window pauses the others, and each window goes full screen on its own. See [What each window has](/en/docs/customize/layouts#what-each-window-has).
- **Strips, copies and particles in node effects:** three new nodes under Units. Clip gradient cuts each line or syllable into coloured strips, each with its own `\clip`. Array copies each unit on a grid, on a circle or along a drawn path, with an angle for `\frz`. Particles spreads copies at random, the same on every run. From a preset adds three examples: Gradient strips, Ring of copies and Particle burst. See [Strips, copies and particles](/en/docs/karaoke/node-effects#strips-copies-and-particles).
- **Proposals in Manual mode:** in the Agent panel's Manual mode, the agent's subtitle edits now come as proposals in the thread, and nothing changes until you press Apply. Decline writes nothing. If the subtitles change while a proposal waits, Ask again makes the agent read them and propose again. See [Proposals](/en/docs/ai/agent#proposals).
- **Skills for the agent:** the Agent panel's agent reads skills, instructions for kinds of work, when your request matches one. Three come with HikariSub: typesetting, translation and karaoke-templater. Add your own as folders with a `SKILL.md`, in the Agent Skills format, in `ai/skills` in your user folder. - **Aegisub folds become line groups:** a file with folds from arch1t3cht's Aegisub offers **Convert to line groups**, also in the Grid's right-click menu. Nested folds become nested groups, collapsed ones closed groups, and it is one undo step. See [Aegisub folds](/en/docs/basics/grid#aegisub-folds).
- **YouTube timed text (srv3):** **File › Export as…** writes srv3 (`.ytt`) exactly as YTSubConverter 1.6.5 does, with each style's YouTube shadow and karaoke colours as options, saved in the subtitle file. **File › Open…** opens `.ytt` and `.srv3` files as a new ASS file, converted back as YTSubConverter does. See [YouTube timed text (srv3)](/en/docs/basics/export#youtube-timed-text-srv3).
- **Plugins update themselves.** Marketplace plugins install new versions on their own, once they finish what they're doing, with **Install updates automatically** under **Plugin updates** and in each plugin's details. An update that asks for more access waits for **Review…**, which marks what's **New**. **Roll back to** returns to the version before, with **Undo**. A plugin the marketplace revokes is turned off, with **Install** for its last good version. The Marketplace's badge now says **Full trust**, as the list does. See [Keeping plugins up to date](/en/docs/plugins/using-plugins#keeping-plugins-up-to-date).
- **Search the font boxes as you type.** The Style manager's **Family** and **File › Settings › Appearance › Program font** filter your fonts as you type, names that start with your text first. You can type in them again on Linux. See [Editing a style](/en/docs/basics/styles#editing-a-style).
- **The plugin marketplace.** The plugin manager's **Marketplace** view lists plugins from the HikariSub marketplace, with their icons and screenshots, search and categories, and installs them after the usual question. Marketplace plugins show **From the marketplace**, get **Update to** a new version from a daily check that sends nothing about your plugins, and a plugin you installed from a file can **Move to the marketplace**. **Plugin updates › Check for plugin updates** turns the check off. See [From the marketplace](/en/docs/plugins/using-plugins#from-the-marketplace).
- **Plugin folders and the internet:** a plugin asks before it uses a folder, and **Remember this folder** lets it keep it until you **Forget** it in the plugin manager. **File › Settings › Updates and privacy › Let plugins connect to the internet** turns off every plugin's connections at once. See [Folders and files](/en/docs/plugins/using-plugins#folders-and-files) and [What is sent](/en/docs/help/what-is-sent#plugins).
- **The window comes back as you left it.** Quitting, loading the last session or recovering from a crash brings the window back where it was, at its size and maximised or not, with its tabs in order and the same tab in front. A window from an unplugged monitor comes back on your main screen. On Wayland, only the size and maximised state come back. See [Sessions](/en/docs/basics/files-and-formats#sessions).
- **Plugins.** **Automation › Plugins…** installs plugins from `.hikariplugin` files, shows what each asks for and who signed it, and turns them on or off. A running plugin's commands sit in the Automation menu, in a submenu named after it, and take shortcuts under the **Plugin shortcuts** filter. Each plugin runs in its own process, with a 10-second limit per command and 256 MB of memory. Plugins can add panels, listed under **View › Panels** and kept in layouts, and dialogs. The plugin manager shows each plugin's permissions, what it adds, its settings and any error, with **Update from file…** and **Open data folder**. See [Using plugins](/en/docs/plugins/using-plugins).
- **Discord presence:** HikariSub can show what you are doing in your Discord status. It is off by default, and the file name is shown only if you turn that on too. See [Discord presence](/en/docs/help/what-is-sent#discord-presence).
- **Typing applies itself in the Karaoke layout:** the Line editor applies your text 300 ms after you stop typing, with no <kbd>Enter</kbd>, and each burst of typing is one undo step. See [Typing applies itself](/en/docs/customize/layouts#typing-applies-itself).
- **Drag a floating panel back from anywhere on its header.** On Linux, pressing the title or the empty part of a floating panel's header now picks the panel up, shows where it can go and docks it when you let go, as on Windows. On Wayland the panel steps out of the way while you drag, so you can drop it onto the panel underneath. To move the window itself, use your desktop's own move binding, such as Super+drag on Hyprland. See [Floating panels](/en/docs/customize/layouts#floating-panels).
- **Resize two panels at once:** drag where the lines between panels meet, and every line that meets there moves with the pointer. Floating panels now resize from each of their edges and corners. See [Moving panels](/en/docs/customize/layouts#moving-panels).
- **Panels open where you can find them.** Shift times, Find and Automation no longer reopen in an old hidden spot or as a floating window. A panel that has no place in your layout now opens in a column to the right of the Grid, and panels opened after it join that column as tabs. The Grid keeps its left edge and gives up width first. Panels that have their own place (Log, Spellchecker, Styles, Template editor, Original text) keep it. Layouts you saved earlier are unchanged. See [Where a panel opens](/en/docs/customize/layouts#where-a-panel-opens).
- **Video › Shift by frames to video:** four commands move the selected lines, or the active line and every line that starts at or after it, by whole frames, so that the active line starts or ends on the frame on screen. See [From the video](/en/docs/basics/timing#from-the-video).
- **Audio › Join with previous line using the audio selection** gives the active line the audio selection, and ends the line before it where the selection starts, in one undo step. See [From the audio](/en/docs/basics/timing#from-the-audio).
- **File › Export as… writes a copy in another format:** SubRip (SRT), WebVTT, YouTube SBV, plain text, MicroDVD, MPL2 or TMPlayer, from all, the selected or the shown lines. The file you are editing stays as it is. A report lists each line that lost something the format can't carry, such as a drawing, a clip or a fade, and choosing one selects it. See [Export](/en/docs/basics/export).
- **Video › Centre times within frames** moves the selected lines' starts and ends to the middle of their frames, keeping each on its frame, so a later shift by time moves every line by whole frames. It is one undo step, and has no key at first. See [Centring times within frames](/en/docs/basics/timing#centring-times-within-frames).
- **Insert start time and Insert end time from video keep a joined neighbour joined:** a line that ended where the selected line started, or started where it ended, moves with it.
- **More is saved with your subtitles**, and survives reopening the file and a trip through Aegisub 3.4 or later:
  - the Perspective tool's surrounding plane, as arch1t3cht's Aegisub saves it. See [The surrounding plane](/en/docs/typesetting/perspective#the-surrounding-plane);
  - which karaoke line each templated line came from, so applying templates to selected lines stays exact after a reopen. See [Applying to selected lines](/en/docs/karaoke/templater#applying-to-selected-lines);
  - the order you placed runs in, in Translation mode. See [Runs](/en/docs/translation/translation-mode#runs);
  - the Kanji timer's skips. A skipped line now has **Pair again**. See [Grouping a line](/en/docs/karaoke/kanji-timer#grouping-a-line).
- **Usage data and crash reports go through HikariSub's own proxy** at `i.hikarisub.org`, which forwards them to PostHog Cloud EU. It keeps no logs and doesn't pass your IP address on. There is no fallback to PostHog's own address. See [Where it goes](/en/docs/help/what-is-sent#where-it-goes).
- **A suggestion to star HikariSub on GitHub:** after real use, a quiet message, "Enjoying HikariSub? A star on GitHub helps others find it.", shows at most twice ever, and never again once you press **Star on GitHub**. With usage data on, its showing and its button send `star_prompt_shown` and `star_prompt_clicked`, with no properties. See [Star on GitHub suggestion](/en/docs/help/what-is-sent#star-on-github-suggestion).
- **Sort lines by text:** **Edit › Sort all lines** and **Sort selected lines** have **Text** and **Text without tags**, which leaves out the `{…}` blocks. Lines with the same text keep their order. See [Sorting](/en/docs/basics/grid#sorting).
- **Scripts written for Aegisub:** scripts get Aegisub 3.5.1's Lua API with the additions of arch1t3cht's fork: pixel colours and pixel data from video frames, Aegisub's rounding in `frame_from_ms` and `ms_from_frame`, and each line's extradata, which is now kept and saved. Aegisub scripts run unchanged, DependencyControl ones included. See [Scripts written for Aegisub](/en/docs/automation/running-scripts#scripts-written-for-aegisub).
- **The interface spells "catalogue" and "capitalisation" throughout**, such as **Manage font catalogues**, **Without catalogue**, **Copy to the catalogue…** and the grammar group **Capitalisation and case**. See [Fonts](/en/docs/typesetting/fonts) and [Styles](/en/docs/basics/styles#catalogues).

### Fixed

- **Claude Code and Codex installed with mise or asdf now work in the Agent panel.** HikariSub finds the real program behind the version manager's shim, where before it ran the version manager itself and the agent didn't start. A Claude Code turn that fails now says what `claude` printed. See [Agents on this computer](/en/docs/ai/agent#agents-on-this-computer).
- **Resample subtitles' Stretch makes text taller, not wider, when the height grows more than the width.** It used to widen the text either way. See [Resolution](/en/docs/basics/files-and-formats#resolution).
- **Subtitle tracks stored compressed in an MKV file now import as text.** They used to come through as unreadable bytes.
- **The Kanji timer skips every kind of space:** plain, full-width and no-break spaces, tabs, `\h` and line breaks. A space separates the kanji or readings on either side of it, but it is never a character or a syllable to time, and the written line keeps its spaces. See [Spaces](/en/docs/karaoke/kanji-timer#spaces).
- **Turning on a screen reader after closing a window no longer crashes HikariSub.**

## 0.1.0-beta.3

Published 2026-10-31. [Release notes](https://github.com/altqx/hikari/releases/tag/v0.1.0-beta.3)

<Callout type="warn" title="Security fix: please update">
  0.1.0-beta.1 and 0.1.0-beta.2 have a security issue in how scripts are loaded. In them, a subtitle file can make HikariSub load and run the Automation scripts it names without asking, and a file in your `include` folder can replace HikariSub's own Lua modules. 0.1.0-beta.3 fixes it, so update if you use an earlier beta. The advisory, [GHSA-g2j7-9r6j-r28v](https://github.com/altqx/hikari/security/advisories/GHSA-g2j7-9r6j-r28v), has the details.
</Callout>

### Security

- **Scripts a subtitle file names ask before they load.** The question shows each script's full path. You can load them, not load them, or always trust their folder. See [Running scripts](/en/docs/automation/running-scripts#scripts-a-subtitle-file-names).
- **HikariSub's own Lua modules always load from the copy that ships with it**, so a file of the same name elsewhere can't replace them. See [Modules](/en/docs/automation/writing-scripts#modules).

### Fixed

- **No more freeze on the first start on Windows.** Getting started mistook HikariSub's own bundled dictionaries for old settings to import, and copied them while the window waited.
- **Saving on Windows no longer fails when another program is reading the file.** A virus scanner, the search indexer or a preview could briefly block the save. HikariSub now retries for up to 3 seconds. If the save still fails, it says the file on disk is unchanged. See [Saving](/en/docs/basics/files-and-formats#saving).
- **Audio keeps playing when its output device goes away.** Playback moves to the system default instead of going silent. See [Output device](/en/docs/basics/audio#output-device).
- **Screen readers read a panel's ⋯ menu in the order it is drawn.** The panel's own items used to be read after Move panel…, Undock and Close.
- **Crash reports from Linux builds have symbols again**, so crashes can be traced to a line.

### New and improved

- **A splash on Windows while HikariSub starts**, with the "Hikari sunrise" artwork in light and dark. See [Install](/en/docs/get-started/install#starting-hikarisub).
- **Full screen bar in the video's right-click menu:** Auto, Always or Never, from the Video panel or in full screen. See [Full screen](/en/docs/basics/video#full-screen).
- **More icons** in menus and toolbars, so commands that shared one icon now have their own.
