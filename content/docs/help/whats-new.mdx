The newest release comes first. Each release's notes on GitHub also list its downloads. [Install](/en/docs/get-started/install) has the current version.

## Next release

Not published yet. These changes are in HikariSub's code and come with the next beta.

### New and improved

- **Plugins can draw their own panels:** a plugin with full trust can draw a panel itself, in QML. It docks like any other panel, and its install question says *Shows its own panels inside HikariSub*. If HikariSub closes while one is open, that plugin's panels wait for **Load again**. See [Plugin panels](/en/docs/plugins/using-plugins#plugin-panels).
- **Karaoke Auto split splits Thai:** each Thai character cluster becomes a syllable, with the line's time shared equally, so `กินน้ำ` becomes `กิ|น|น้ำ`. **File › Settings › Audio › Karaoke › Split Thai into character clusters**, on by default, turns it off to keep each Thai word one syllable. Thai support is by Jibrill. See [Auto split](/en/docs/karaoke/split-and-join#auto-split).
- **Connect Claude Code or Codex:** **File › Settings › AI › MCP › Let agents outside HikariSub edit through MCP** lets an AI agent you run yourself read your open files and edit them. **Copy setup** copies the Claude Code command, the Codex settings, or for agents that connect over HTTP, the address and token. Every edit the agent makes waits in the new **Review panel**, and in the Grid and the Line editor, until you **Keep** or **Undo** it, and **Restore checkpoint** goes back to before a turn. See [Connect Claude Code or Codex](/en/docs/ai/connect-an-agent) and [Reviewing AI changes](/en/docs/ai/review).
- **More than one window:** drag a tab out of the tab row into a new window, or onto another window's tab row, or use **Move tab to new window** and **Move tab to window ›** in the tab's menu. Each window has its own tabs, panels and layout, and Styles, Find and the other tool panels work on its own file. Closing a window asks only about its own changes, and closing the last one quits. Sessions bring back every window. See [Windows](/en/docs/customize/layouts#windows).
- **Thai in Automation scripts:** the Automation menu has **Letter spacing to positioned clusters…**, which turns `\fsp` letter spacing into one positioned line per character cluster, so Thai vowel and tone marks stay on their letters. **Bezier Curve Imposition** keeps Thai and other combining marks with their base letter along the curve. Scripts can go through grapheme clusters with `unicode.graphemes`. Thai support is by Jibrill, credited in **Help › Credits**. See [Running a macro](/en/docs/automation/running-scripts#running-a-macro).
- **Plugins can look at the video:** the Hikari API, which plugins reach with `hikari.call`, adds `video.frame`, which can draw one line alone and crop the frame, plus `video.ink_bounds`, `video.colours`, with the ASS colours at up to 256 points, and `video.keyframes`. See [docs/api.md](https://github.com/altqx/hikari/blob/main/docs/api.md) in HikariSub's repository.
- **Plugins run in a sandbox:** on Linux and Windows, ordinary plugins now run in an operating-system sandbox, where they reach only their own package and have no network of their own. Full trust plugins run outside it, with the same access as HikariSub. Where the sandbox can't apply, the plugin's details say so. See [Safety and limits](/en/docs/plugins/using-plugins#safety-and-limits).
- **Install in HikariSub** on the marketplace website opens HikariSub at that plugin, checks it against HikariSub's own signed list, and asks the usual install question. The Windows installer and the Linux packages register the `hikarisub://` links it uses; the Windows portable zip doesn't. See [From the marketplace website](/en/docs/plugins/using-plugins#from-the-marketplace-website).
- **QC notes**, under **Subtitles › QC notes…**: a panel for the notes of a QC pass, kept in the subtitle file itself, where Aegisub keeps them too. Each note has a time, a section and a **Done** box, the Grid flags the line it marks, and **Previous** and **Next** go through them. It imports arch1t3cht's Note Browser and mpvQC notes, and exports Note Browser's. See [QC notes](/en/docs/checking/qc-notes).
- **Perspective tracking:** **Video › Perspective tracking…** applies After Effects Power-Pin tracking data to the selected lines frame by frame, like arch1t3cht's Perspective-Motion script. See [Perspective tracking](/en/docs/typesetting/perspective#perspective-tracking).
- **Open any right-click menu from the keyboard** with the <kbd>Menu</kbd> key or <kbd>Shift</kbd>+<kbd>F10</kbd>. It opens at the text cursor, the current row or the video cursor. See [Right-click menus](/en/docs/get-started/tour#right-click-menus).
- **Menus show each command's current key**, and follow your changes in **File › Settings › Shortcuts**.
- **One menu for every text field:** Undo, Redo, Cut, Copy, Paste, Delete and Select all, each doing what its key does in that field. Right-click now works in time and number fields too, and drop-down lists you can type in, such as **Actor** and **Effect**, have the same menu.
- **Tidier Grid menus.** The right-click menu groups its commands into **Insert**, **Paste special**, **Join**, **Split** and **Make times continuous** submenus, names how many lines **Duplicate** and **Delete** act on, and ends with **Delete**. Right-click the column names for the list of columns. The Grid's **⋯** menu now has **Filtering** and **Columns**. See [The right-click menu](/en/docs/basics/grid#the-right-click-menu).
- **Set FPS and Import subtitles from MKV are in the menu bar**, under **Subtitles › Set FPS** and **File › Import subtitles from MKV…**. **Paste translation text** is now **Paste translation from a file…**, and **Dialogue shifting window** is **Translation matching…**.
- **The tag list has a ⋯ options button**, and tag buttons and line groups open their menus from the keyboard too. See [Tag buttons](/en/docs/basics/line-editor#tag-buttons).
- **WebM, VP8, VP9 and AV1:** WebM videos open, with VP8, VP9 or AV1 video and Vorbis or Opus sound, and the audio picker lists `.webm`, `.mka` and `.opus`. AV1 plays only with a hardware AV1 decoder; without one, its frames still show while paused, and seeking and stepping work. HikariSub now includes dav1d (BSD-2-Clause) to read AV1, and Credits lists it. See [Formats](/en/docs/basics/video#formats).
- **Settings says shortcut, not hotkey.** The pages are renamed: **Hotkeys** is now **Shortcuts**, **Subtitle grid** is **Grid**, **Subtitle properties** is **Script properties**, and **Spelling & grammar** is **Spelling and grammar**. On the Shortcuts page, **Import legacy hotkeys…** is now **Import legacy shortcuts…**, and the Appearance page spells **Accent colour**, **UI colours** and, for high contrast, **Border colour**. The Spellchecker's **Ignore All** is **Ignore all**. The Grid's **Styles** column is **Style**, the Line editor's **Not confirmed** is **Unconfirmed**, its colour buttons and their shortcuts say **colour**, such as **Primary colour**, and a tag button's **Insert Tag at text beginning** is **Insert tag at start of text**. In the menus, **Open auto save** is **File › Open autosave…**, **ASS file properties** is **Subtitles › Script properties**, **Edit › Sort** has **Start time** and **Style**, the Line editor's **Font selection** is **Choose font…**, and a tab's **⋯** menu has **Show subtitles in folder** and the like. Button tips say **Shift+click to set a shortcut**. **Subtitles › Kanji timer** has no **…**, and **Edit › Select lines** has **Style** among its fields. See [Shortcuts](/en/docs/customize/hotkeys).
- **One Find panel.** The Search panel and its Find, Replace and In files tabs are now one **Find** panel. The **▸** button shows the replace row, the options fold behind **Options** with chips for the ones you changed, and paired check boxes became choices: **Lines**, **In text** and **Match at**. **Search in** chooses this document, the open documents or a **Folder**. A count shows *3 of 12* as you type, regular expression errors show under the field, and **Edit › Find previous** (<kbd>Shift</kbd>+<kbd>F3</kbd>) goes back. The search wraps without asking. See [Find and replace](/en/docs/basics/find-and-replace).
- **Import legacy settings moved to Settings › General**, in a new **Legacy** section at the end, with **Roll back the last import…** after an import and **Import legacy shortcuts…**, which moved there from the Shortcuts page. A note says when no legacy installation is found. The File menu item is gone; the command can be given a key in **Settings › Shortcuts**. See [Moving from legacy](/en/docs/get-started/moving-from-legacy#importing-your-settings).
- **Zoom and pan the video as in Aegisub 3.5:** <kbd>Ctrl</kbd>+wheel zooms around the pointer, <kbd>Shift</kbd>+wheel pans, a middle-button drag pans once the pointer has moved 3 pixels, and a touchpad pinch zooms. The plain wheel no longer zooms the video by default. Visual tools that use the wheel or the middle button keep them. **File › Settings › Video › View › Zoom and pan** brings back HikariSub legacy's crop zoom, and three rows there choose what the wheel, <kbd>Ctrl</kbd>+wheel and <kbd>Shift</kbd>+wheel do. **Video › Turn off video zoom** is now **Reset zoom and pan**, and resets both. See [Zoom and pan](/en/docs/basics/video#zoom-and-pan).
- **Border type and text direction in styles:** the Style manager's **Opaque box** check box is now a **Border type** choice: **Outline**, **Opaque box** or **Opaque box per line (libass)**, and files that use the per-line box keep it. **Text encoding** has **-1 - Detect text direction (libass)**, so Arabic and Hebrew lines read right to left. Scripts read and write a style's `borderstyle` as 1, 3 or 4, as in Aegisub, where it used to be 0 or 1. See [Editing a style](/en/docs/basics/styles#editing-a-style).
- **Shift times and the Timing postprocessor are two panels**, opened from **Subtitles › Shift times…** and **Subtitles › Timing postprocessor…**. Each previews the lines it would change and names its effect on **Apply**, such as **Shift 214 lines**. It says why a choice can't run, and offers **Open video…** or **Open keyframes…**. Each has its own presets, and your Shift times profiles became presets. Shift times has **Centre times within frames**, which puts the shifted times in the middle of their frames. A postprocessor preset marked **Use in the Timing layout** is applied when you choose that layout, which now opens the postprocessor beside the Audio. See [Shift times](/en/docs/basics/timing#shift-times).
- **Line editor additions from Aegisub 3.5:**
  - **Edit › Insert hard space** (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd>) puts `\h` at the cursor.
  - **File › Settings › Line editor › Shift+Enter inserts a soft line break (\n)**, off at first, makes <kbd>Shift</kbd>+<kbd>Enter</kbd> put in `\n` instead of `\N`.
  - Time fields go up to 99:59:59.99, and longer times in a file are kept unless you edit them.
  - `mixin` lines are coloured like `template` lines.
  - Drawing and vector clip coordinates alternate their X and Y colours in every theme.

  See [The Line editor](/en/docs/basics/line-editor#the-text).
- **Line groups inside line groups:** **Make line group** on lines inside a group makes a group within it, and on whole groups takes them in. Each level is indented a little further, every group opens and closes on its own, and closing one hides everything inside. **Ungroup** moves what was inside up one level, **Select the group's lines** takes inner groups too, and a pasted group goes in at the level where you paste it. Files without nesting save as before. HikariSub 0.0.x opens nested groups as flat ones, and loses the nesting if it saves. See [Groups inside groups](/en/docs/basics/grid#groups-inside-groups).
- **Tidier video and audio menus.** The video's right-click menu groups frame export under **Export frame ›**, has **Audio track ›**, **Chapters ›** and **Reset zoom and pan**, and keeps the full-screen rows (**Open editor**, the files, **Recently opened ›**, **Progress bar** and **Full screen bar ›**) for full screen. The bar's modes are **Show when the pointer moves**, **Always show** and **Never show**. In full screen, <kbd>Shift</kbd>+<kbd>Tab</kbd> reaches the speaker button, and <kbd>Menu</kbd> opens its output menu. The Audio panel's overflow is **»**, with **Tap options ›** and **Speech spectrum**, and its options are called **Auto-commit**, **Go to the next line after commit** and **Karaoke** everywhere. See [The right-click menu](/en/docs/basics/video#the-right-click-menu).
- **Split into frames bakes animations.** **Grid › Split › Into frames** now gives each frame's line the values its `\t` tags have reached, its `\fad` or `\fade` in its alphas, and its `\move` as a `\pos`. **Split › Bake animations**, or **File › Settings › Grid › Splitting**, turns this off for the split from before, where only `\move` changes. It is on by default. See [Baking animations](/en/docs/basics/grid#baking-animations).
- **Audio display from Aegisub 3.5:** the paused video's frame and the one before it are shaded on the audio display. With **Snap to keyframes** on, a dragged boundary also snaps to the middle of either frame, where a line starts or ends on that frame. **Go to selection start** and **Go to selection end** centre the view on either end of the selection. They have no key at first, and they are in the Audio panel's **»** menu. See [The Audio panel](/en/docs/basics/audio#what-the-display-shows).
- **Resampling keeps 3D-rotated signs in shape:** **Subtitles › Resample subtitles** has **Adjust 3D rotations**, on by default. Lines turned with `\frx` or `\fry` keep their shape on screen, as with arch1t3cht's Resample Perspective. Lines that move, change shape over time or can't be measured are only scaled, and one Log notice lists them. Resampling also no longer overwrites `LayoutResX` and `LayoutResY`. It keeps `LayoutResY` and changes `LayoutResX` with the aspect ratio, and **Change resolution only** leaves both alone. See [Resolution](/en/docs/basics/files-and-formats#resolution).
- **Tidier panel, tab and style menus.** Each panel's **⋯** menu ends with **Float** or **Dock**, then **Close** on its own, and **View › Panels** gives each panel **Show**, **Float** or **Dock**, and **Close**. **Show times** and **Show frames** moved to the Line editor's **⋯**, and the video's follow options are now called **Move video to the selected line** and **After moving, play**, in the menu and in Settings. A tab's menu adds **Close other tabs**, **Close tabs to the right**, **Switch to ›**, **Show in folder** and **Copy path**, and <kbd>Menu</kbd> or <kbd>Shift</kbd>+<kbd>F10</kbd> opens it. The Styles panel's menus say **New style…**, **Edit style…** and **Style manager**. The reference's menu has **Copy**, and **Also in** lists where the right-clicked line appears in other files. See [Tabs](/en/docs/basics/files-and-formats#tabs).
- **Signed releases:** each release now signs `SHA256SUMS` and the update file with HikariSub's release key (minisign, key id A97C7A20EFD98999), as `SHA256SUMS.minisig` and `hikarisub-update.json.minisig`. The update check installs only signed releases: it skips one whose signature is missing or wrong, and only announces one without the update file. [Checking a download](/en/docs/get-started/install#checking-a-download) has the key and the commands to check a package by hand.
- **Export as TTML and DFXP:** **File › Export as…** writes **TTML (IMSC1)** and **DFXP**. Styles, bold, italics, colours and outlines carry over, and each line sits at the top, middle or bottom with its alignment. The options are **Times in frames**, a **Language** code, and a **Netflix timed-text style**: white, centred, top or bottom, italics only, with frame times. The report says which lines' positions were approximated. See [Formats](/en/docs/basics/export#formats).
- **Lock your layout.** **View › Layout › Lock layout**, also in the layout switcher and each panel's **⋯** menu, keeps every panel where it is: nothing undocks, floats or moves by accident, and you can still resize panels by their edges. Dock any floating panel first. The lock is kept with the tab, the session and saved layouts. See [Locking the layout](/en/docs/customize/layouts#locking-the-layout).
- **Save as converts to ASS.** **Subtitles › Conversion** is gone. To turn an SRT or another format into ASS, choose ASS in **File › Save as…**: HikariSub lists what will change and asks first, and the conversion is one undo step. **File › Settings › Conversion** still sets how. Keys you gave the old convert commands are removed, with a notice that says what to use instead. See [Saving as ASS](/en/docs/basics/files-and-formats#saving-as-ass).
- **Timecodes files:** **Video › Open timecodes** loads a v1, v2 or v4 file, and frames, timing, seeking and scripts follow its times. **Save timecodes** writes a v2 file, **Close timecodes** goes back to the video's times, and there is a recent list. Each tab keeps its own, an ASS file remembers it as in Aegisub, and the session brings it back. See [Timecodes](/en/docs/basics/video#timecodes).
- **Align to video:** **Video › Align to video…** times the active line to the frames where a point you click keeps its colour, within a **Tolerance**, as in Aegisub. See [Aligning to the video](/en/docs/basics/video#aligning-to-the-video).
- **Video from Aegisub 3.5:**
  - Opening a video asks to set or change the subtitles' YCbCr matrix and layout resolution, and warns about untagged, HDR or wide-gamut colours, each with a row in **File › Settings › Video › Script resolution**. See [Opening a video](/en/docs/basics/video#opening-a-video).
  - **Video › Reload video** and **Audio › Reload audio** open the same file again where you were.
  - **Video › Video details…** shows the file's resolution, exact frame rate, frame count, length, colour space and matrix.
  - **Export frame ›** adds **Save subtitles only as PNG…** and **Copy subtitles only**, the subtitles alone on transparency.
  - A dummy video takes a fractional frame rate such as 24000/1001, up to 100000 pixels a side, and a 1080x1920 preset.
  - When linked video, audio, keyframes or timecodes files are missing, the bar lists them under *Linked files not found:*.
  - With a timecodes file loaded, **Video details…** calls the frame rate **Video stream frame rate** and names the file under **Frame times from**.
  - **File › Settings › Video › Visual tools › Handle size** scales the visual tools' handles, vector clips keep two decimals, and the vector clip modes and **Invert clip** can take keys.
- **Font collector asks before replacing fonts** in a folder that already has some of them: **Replace**, **Keep existing** or **Cancel**. See [Copying and zipping](/en/docs/typesetting/fonts#copying-and-zipping).
- **Play in mono:** **File › Settings › Audio › Playback › Play in mono** mixes the Audio panel's playback down to one channel. See [Settings](/en/docs/basics/audio#settings).
- **Aegisub folds become line groups:** a file with folds from arch1t3cht's Aegisub offers **Convert to line groups**, also in the Grid's right-click menu. Nested folds become nested groups, collapsed ones closed groups, and it is one undo step. See [Aegisub folds](/en/docs/basics/grid#aegisub-folds).
- **YouTube timed text (srv3):** **File › Export as…** writes srv3 (`.ytt`) exactly as YTSubConverter 1.6.5 does, with each style's YouTube shadow and karaoke colours as options, saved in the subtitle file. **File › Open…** opens `.ytt` and `.srv3` files as a new ASS file, converted back as YTSubConverter does. See [YouTube timed text (srv3)](/en/docs/basics/export#youtube-timed-text-srv3).
- **Plugins update themselves.** Marketplace plugins install new versions on their own, once they finish what they're doing, with **Install updates automatically** under **Plugin updates** and in each plugin's details. An update that asks for more access waits for **Review…**, which marks what's **New**. **Roll back to** returns to the version before, with **Undo**. A plugin the marketplace revokes is turned off, with **Install** for its last good version. The Marketplace's badge now says **Full trust**, as the list does. See [Keeping plugins up to date](/en/docs/plugins/using-plugins#keeping-plugins-up-to-date).
- **Search the font boxes as you type.** The Style manager's **Family** and **File › Settings › Appearance › Program font** filter your fonts as you type, names that start with your text first. You can type in them again on Linux. See [Editing a style](/en/docs/basics/styles#editing-a-style).
- **The plugin marketplace.** The plugin manager's **Marketplace** view lists plugins from the HikariSub marketplace, with their icons and screenshots, search and categories, and installs them after the usual question. Marketplace plugins show **From the marketplace**, get **Update to** a new version from a daily check that sends nothing about your plugins, and a plugin you installed from a file can **Move to the marketplace**. **Plugin updates › Check for plugin updates** turns the check off. See [From the marketplace](/en/docs/plugins/using-plugins#from-the-marketplace).
- **Plugin folders and the internet:** a plugin asks before it uses a folder, and **Remember this folder** lets it keep it until you **Forget** it in the plugin manager. **File › Settings › Updates and privacy › Let plugins connect to the internet** turns off every plugin's connections at once. See [Folders and files](/en/docs/plugins/using-plugins#folders-and-files) and [What is sent](/en/docs/help/what-is-sent#plugins).
- **The window comes back as you left it.** Quitting, loading the last session or recovering from a crash brings the window back where it was, at its size and maximised or not, with its tabs in order and the same tab in front. A window from an unplugged monitor comes back on your main screen. On Wayland, only the size and maximised state come back. See [Sessions](/en/docs/basics/files-and-formats#sessions).
- **Plugins.** **Automation › Plugins…** installs plugins from `.hikariplugin` files, shows what each asks for and who signed it, and turns them on or off. A running plugin's commands sit in the Automation menu, in a submenu named after it, and take shortcuts under the **Plugin shortcuts** filter. Each plugin runs in its own process, with a 10-second limit per command and 256 MB of memory. Plugins can add panels, listed under **View › Panels** and kept in layouts, and dialogs. The plugin manager shows each plugin's permissions, what it adds, its settings and any error, with **Update from file…** and **Open data folder**. See [Using plugins](/en/docs/plugins/using-plugins).
- **Discord presence:** HikariSub can show what you are doing in your Discord status. It is off by default, and the file name is shown only if you turn that on too. See [Discord presence](/en/docs/help/what-is-sent#discord-presence).
- **Typing applies itself in the Karaoke layout:** the Line editor applies your text 300 ms after you stop typing, with no <kbd>Enter</kbd>, and each burst of typing is one undo step. See [Typing applies itself](/en/docs/customize/layouts#typing-applies-itself).
- **Drag a floating panel back from anywhere on its header.** On Linux, pressing the title or the empty part of a floating panel's header now picks the panel up, shows where it can go and docks it when you let go, as on Windows. On Wayland the panel steps out of the way while you drag, so you can drop it onto the panel underneath. To move the window itself, use your desktop's own move binding, such as Super+drag on Hyprland. See [Floating panels](/en/docs/customize/layouts#floating-panels).
- **Resize two panels at once:** drag where the lines between panels meet, and every line that meets there moves with the pointer. Floating panels now resize from each of their edges and corners. See [Moving panels](/en/docs/customize/layouts#moving-panels).
- **Panels open where you can find them.** Shift times, Find and Automation no longer reopen in an old hidden spot or as a floating window. A panel that has no place in your layout now opens in a column to the right of the Grid, and panels opened after it join that column as tabs. The Grid keeps its left edge and gives up width first. Panels that have their own place (Log, Spellchecker, Styles, Template editor, Original text) keep it. Layouts you saved earlier are unchanged. See [Where a panel opens](/en/docs/customize/layouts#where-a-panel-opens).
- **Video › Shift by frames to video:** four commands move the selected lines, or the active line and every line that starts at or after it, by whole frames, so that the active line starts or ends on the frame on screen. See [From the video](/en/docs/basics/timing#from-the-video).
- **Audio › Join with previous line using the audio selection** gives the active line the audio selection, and ends the line before it where the selection starts, in one undo step. See [From the audio](/en/docs/basics/timing#from-the-audio).
- **File › Export as… writes a copy in another format:** SubRip (SRT), WebVTT, YouTube SBV, plain text, MicroDVD, MPL2 or TMPlayer, from all, the selected or the shown lines. The file you are editing stays as it is. A report lists each line that lost something the format can't carry, such as a drawing, a clip or a fade, and choosing one selects it. See [Export](/en/docs/basics/export).
- **Video › Centre times within frames** moves the selected lines' starts and ends to the middle of their frames, keeping each on its frame, so a later shift by time moves every line by whole frames. It is one undo step, and has no key at first. See [Centring times within frames](/en/docs/basics/timing#centring-times-within-frames).
- **Insert start time and Insert end time from video keep a joined neighbour joined:** a line that ended where the selected line started, or started where it ended, moves with it.
- **More is saved with your subtitles**, and survives reopening the file and a trip through Aegisub 3.4 or later:
  - the Perspective tool's surrounding plane, as arch1t3cht's Aegisub saves it. See [The surrounding plane](/en/docs/typesetting/perspective#the-surrounding-plane);
  - which karaoke line each templated line came from, so applying templates to selected lines stays exact after a reopen. See [Applying to selected lines](/en/docs/karaoke/templater#applying-to-selected-lines);
  - the order you placed runs in, in Translation mode. See [Runs](/en/docs/translation/translation-mode#runs);
  - the Kanji timer's skips. A skipped line now has **Pair again**. See [Grouping a line](/en/docs/karaoke/kanji-timer#grouping-a-line).
- **Usage data and crash reports go through HikariSub's own proxy** at `i.hikarisub.org`, which forwards them to PostHog Cloud EU. It keeps no logs and doesn't pass your IP address on. There is no fallback to PostHog's own address. See [Where it goes](/en/docs/help/what-is-sent#where-it-goes).
- **A suggestion to star HikariSub on GitHub:** after real use, a quiet message, "Enjoying HikariSub? A star on GitHub helps others find it.", shows at most twice ever. Turn it off in **File › Settings › Updates and privacy › Privacy › Suggest starring HikariSub on GitHub**. With usage data on, its showing and its button send `star_prompt_shown` and `star_prompt_clicked`, with no properties. See [Star on GitHub suggestion](/en/docs/help/what-is-sent#star-on-github-suggestion).
- **Sort lines by text:** **Edit › Sort all lines** and **Sort selected lines** have **Text** and **Text without tags**, which leaves out the `{…}` blocks. Lines with the same text keep their order. See [Sorting](/en/docs/basics/grid#sorting).
- **Scripts written for Aegisub:** scripts get Aegisub 3.5.1's Lua API with the additions of arch1t3cht's fork: pixel colours and pixel data from video frames, Aegisub's rounding in `frame_from_ms` and `ms_from_frame`, and each line's extradata, which is now kept and saved. Aegisub scripts run unchanged, DependencyControl ones included. See [Scripts written for Aegisub](/en/docs/automation/running-scripts#scripts-written-for-aegisub).
- **The interface spells "catalogue" and "capitalisation" throughout**, such as **Manage font catalogues**, **Without catalogue**, **Copy to the catalogue…** and the grammar group **Capitalisation and case**. See [Fonts](/en/docs/typesetting/fonts) and [Styles](/en/docs/basics/styles#catalogues).

### Fixed

- **Resample subtitles' Stretch makes text taller, not wider, when the height grows more than the width.** It used to widen the text either way. See [Resolution](/en/docs/basics/files-and-formats#resolution).
- **Subtitle tracks stored compressed in an MKV file now import as text.** They used to come through as unreadable bytes.
- **The Kanji timer skips every kind of space:** plain, full-width and no-break spaces, tabs, `\h` and line breaks. A space separates the kanji or readings on either side of it, but it is never a character or a syllable to time, and the written line keeps its spaces. See [Spaces](/en/docs/karaoke/kanji-timer#spaces).

## 0.1.0-beta.3

Published 2026-10-31. [Release notes](https://github.com/altqx/hikari/releases/tag/v0.1.0-beta.3)

<Callout type="warn" title="Security fix: please update">
  0.1.0-beta.1 and 0.1.0-beta.2 have a security issue in how scripts are loaded. In them, a subtitle file can make HikariSub load and run the Automation scripts it names without asking, and a file in your `include` folder can replace HikariSub's own Lua modules. 0.1.0-beta.3 fixes it, so update if you use an earlier beta. The advisory, [GHSA-g2j7-9r6j-r28v](https://github.com/altqx/hikari/security/advisories/GHSA-g2j7-9r6j-r28v), has the details.
</Callout>

### Security

- **Scripts a subtitle file names ask before they load.** The question shows each script's full path. You can load them, not load them, or always trust their folder. See [Running scripts](/en/docs/automation/running-scripts#scripts-a-subtitle-file-names).
- **HikariSub's own Lua modules always load from the copy that ships with it**, so a file of the same name elsewhere can't replace them. See [Modules](/en/docs/automation/writing-scripts#modules).

### Fixed

- **No more freeze on the first start on Windows.** Getting started mistook HikariSub's own bundled dictionaries for old settings to import, and copied them while the window waited.
- **Saving on Windows no longer fails when another program is reading the file.** A virus scanner, the search indexer or a preview could briefly block the save. HikariSub now retries for up to 3 seconds. If the save still fails, it says the file on disk is unchanged. See [Saving](/en/docs/basics/files-and-formats#saving).
- **Audio keeps playing when its output device goes away.** Playback moves to the system default instead of going silent. See [Output device](/en/docs/basics/audio#output-device).
- **Screen readers read a panel's ⋯ menu in the order it is drawn.** The panel's own items used to be read after Move panel…, Undock and Close.
- **Crash reports from Linux builds have symbols again**, so crashes can be traced to a line.

### New and improved

- **A splash on Windows while HikariSub starts**, with the "Hikari sunrise" artwork in light and dark. See [Install](/en/docs/get-started/install#starting-hikarisub).
- **Full screen bar in the video's right-click menu:** Auto, Always or Never, from the Video panel or in full screen. See [Full screen](/en/docs/basics/video#full-screen).
- **More icons** in menus and toolbars, so commands that shared one icon now have their own.
