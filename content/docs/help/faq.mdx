## Releases and installing

### Is HikariSub 0.1 released?

Not yet. The first release will be 0.1.0-beta.1. This site gives no date for it.

### Which systems does it run on?

Windows 10 version 1809 or later and Windows 11, 64-bit, and 64-bit (x86_64) Linux with glibc 2.34 or later. There is no ARM build. See [Install](/en/docs/get-started/install#what-you-need).

### Why does Windows warn me about the setup?

The packages are not code-signed, so Windows says the publisher is unknown. Each release lists the SHA-256 checksum of every package in `SHA256SUMS`, to check your download against.

### Which version do I have?

**Help › About** shows it with the package kind, and **Copy version** copies it. From a terminal, run `hikarisub --version` (see [Command line](/en/docs/reference/command-line#switches)).

## Privacy

### Does HikariSub connect to the internet?

Yes:

- **Anonymous usage data**, which is **on by default**. HikariSub sends which features are used, errors and crashes, and how fast things open to PostHog Cloud EU, under a random ID, and the IP address is discarded. It never sends your files, their names or what is in them. [What is sent](/en/docs/help/what-is-sent) lists every event. Only release packages send it.
- **Crash and freeze reports**, only when you press **Send report** in a report's window or turn on **Always send crash reports**, even with usage data off. See [Crash and freeze reports](/en/docs/help/reporting-problems#crash-and-freeze-reports).
- **The update check**, which is off by default: when you choose **Help › Check for updates**, or at most once a day when it starts if you turn on **File › Settings › Updates and privacy › Check for updates automatically**. The check asks GitHub (`api.github.com`) for the list of releases, so GitHub sees your IP address. **What's new** reads the same list and never loads the images or links in the release notes. See [Updates](/en/docs/get-started/install#updates).
- **DependencyControl**, which comes with HikariSub, checks its scripts' feeds for updates by itself. See [Updating scripts](/en/docs/automation/dependencycontrol#updating-scripts).

To turn off the usage data, use any of these:

- **File › Settings › Updates and privacy › Privacy › Send anonymous usage data**
- **Send anonymous usage data** on the Updates and privacy step of the [Getting started window](/en/docs/get-started/getting-started-window#updates-and-privacy)
- `DO_NOT_TRACK=1` in the environment, for each run that has it

The [grammar check](/en/docs/checking/grammar#harper) runs on your computer and sends nothing.

## Legacy and files

### Can I keep my settings from HikariSub 0.0.x?

Yes. **File › Import legacy settings…** brings them over, and never changes the legacy files. See [Moving from legacy](/en/docs/get-started/moving-from-legacy).

### Where are my settings, autosaves and scripts?

In your [user folder](/en/docs/automation/user-folder). **Help › Open user folder** opens it. [Troubleshooting](/en/docs/help/troubleshooting#where-things-are) lists where it is.

### Is there a log file?

No. The Log panel starts empty at each start. Copy its entries with **Copy** before you quit if you need them. HikariSub keeps only the last 200 lines, with file names, text and folders replaced, for a [crash report](/en/docs/help/reporting-problems#what-a-report-holds). See [The Log panel](/en/docs/help/troubleshooting#the-log-panel).

### Does HikariSub save crash reports?

Yes, a small record of a crash or a freeze, with no file names or text, in the cache folder: `crash-record.txt` or `hang-record.txt` in `~/.cache/hikarisub` on Linux, `%LOCALAPPDATA%\HikariSub\cache` on Windows. The report made from it waits in the `reports` folder there. It writes no crash dumps. At the next start after a crash or a freeze, a window shows the whole report and you choose: **Send report**, **Open GitHub issue** or **Don't send**. See [Crash and freeze reports](/en/docs/help/reporting-problems#crash-and-freeze-reports). The same window offers your last session and autosaves: see [After a crash](/en/docs/help/troubleshooting#after-a-crash).

## Automation

### Do my Aegisub scripts work?

HikariSub runs Automation 4 scripts on LuaJIT, in Lua or MoonScript. DependencyControl and Aegisub-Motion come with it. See [Writing scripts](/en/docs/automation/writing-scripts).

### Can scripts add export filters?

No. HikariSub has no Export command, and a script's `register_filter` does nothing.

### Why aren't my macros in submenus?

The Automation menu lists every macro in one flat list. A `/` in a macro's name doesn't make a submenu.

### Can two macros run at the same time?

No. One macro runs at a time.

## Languages

### Which languages is the interface in?

English, with partial translations into Polish, Korean, Thai and Tamil.

### Which languages can it check the spelling of?

The Windows packages bring English (US), Polish and Thai dictionaries. For other languages, add the language's `.dic` and `.aff` files to the `dictionaries` folder in your [user folder](/en/docs/automation/user-folder).

### Can it check grammar?

Yes, in English only: US, UK, Canadian or Australian English. The check uses Harper, which comes with HikariSub, and is off at first. See [Grammar](/en/docs/checking/grammar).
